PaperWallah - JavaFX (Java 17+, Maven)
Run:   mvn javafx:run
Test:  mvn test
Fully offline: no network, database server or API is used. Data is saved locally in PaperWallah/data (questions.dat, papers.dat) and PaperWallah/images. No internet needed.
Blueprint format (Generate tab): name,count,marksEach[,topic[,EASY|MEDIUM|HARD]]
